Independent worlds never collide with each other. Fused ensemble mode shares one solver graph and GPU storage; other modes retain separate world graphs. Use the same body count and workload when comparing batched and separate submission. Use one world to measure single-world latency.

Each world uses local float32 coordinates and a double-precision global origin. This example places world origins one billion units apart. Resident memory includes buffers, GPU reset snapshots and graph scratch, excluding pipelines and driver overhead.

Timing covers encoding, submission and GPU completion. Compilation, diagnostics, final-state drawing and recycling are reported separately or excluded. A successful completion flag does not establish physical accuracy. Ensembles share one rollback boundary and contact budget, omit reset checkpoints, and currently exclude joints, CCD and authored triggers. At most 65,535 bodies and colliders fit in one ensemble. Recycling applies only to separate-world modes.
