This optional integration keeps graph analytics inside `@luma.gl/experimental/lugraph` and
deck.gl-specific rendering inside an unpackaged example. A real deck.gl `Effect` builds forward and
reverse GPU adjacency, computes dangling-aware PageRank and weak-component labels once, then
progressively advances bounded neighborhood search and force-directed layout on deck.gl's existing
WebGPU command encoder.

The custom node layer binds the exact `float32x2` position allocation as its instance vertex
attribute. PageRank scores control node size, weak-component identifiers control color, and
source-aligned breadth-first outputs highlight selected neighborhoods. One custom edge layer reads
each original nonempty source/target GPU chunk directly; the empty partition is retained in the
graph and never repacked.

Use the orthographic view to pan and zoom. Click a node to select its neighborhood, drag to pin its
GPU-resident coordinates, adjust the hop limit, clear pins, or reset the deterministic layout.
deck.gl's asynchronous WebGPU picking resolves stable original vertex identifiers only when
interaction requests a pick; ordinary animation never reads graph columns back to the CPU.
