The viewer opens a 4096 × 4096 bake made with 768 samples. To try your own lighting,
export a completed Cornell Box bake from [Lightmap Baking](/examples/api/lightmap-baking)
and open the `.lmb` file here. The viewer checks the source asset and atlas recipe,
then uses the stored irradiance to light the scene.
