The Satellite Raster Lab generates a deterministic, entirely synthetic
earth-observation scene with red and near-infrared reflectance bands, farmland,
vegetation, waterways, cloud cover, and out-of-footprint nodata. Switch between
the derived vegetation index and its source bands, adjust analytical contrast or
gamma, select pixels above a live classification threshold, or increase the
denominator epsilon to reject unstable normalized-difference measurements.
An optional Otsu control derives its threshold directly from an unfiltered GPU
histogram before classifying the same resident pixels.
Every control changes the GPU-computed distribution, selected-pixel count,
observed extent, and mean when its underlying values or selection change.

The demonstration uses the optional `@luma.gl/experimental/luraster` entry point.
`GPURasterNDVI` computes `(nearInfrared - red) / (nearInfrared + red)` directly
from GPU-resident source bands while intersecting source validity and exact raw
nodata. `GPURasterHistogram` composes a masked reduction with a GPU-domain
histogram. `GPURasterContrast` transforms the active spectral band on-device;
`GPURasterThreshold` writes a genuine per-pixel selection mask; and
`GPURasterStatistics` calculates masked count, sum, mean, minimum, and maximum.
`GPURasterOtsuThreshold` can select the threshold from a separate baseline
histogram without introducing a CPU synchronization point.
The histogram consumes that same mask and GPU-resident extent, so excluded
pixels disappear from both the map selection and distribution. Every dependent
compute pass is encoded into one explicitly submitted `GPUCommandGraph`.

The map renderer consumes the original reflectance bands, derived vegetation
index, contrast-adjusted active band, and validity flags directly from their GPU
buffers. Only the two-value extent, 48 histogram bins, valid count, sum, and
mean, and optional automatic threshold—216 bytes total—are copied back after
submission to update visible summary
statistics. Layer switching, contrast, gamma, thresholding, and epsilon rebuild
their specialized analysis graph while keeping every source and output raster
buffer resident; source pixels are never downloaded.

All imagery, coordinates, and terrain are synthetic. The visualization is a
false-color illustration, not a real satellite acquisition, true-color image,
georeferenced location, or scientifically calibrated product. Convolution,
morphology, segmentation, contour extraction, and tiled imagery shown in the
interface are planned capabilities rather than implemented features.
