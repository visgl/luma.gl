The application registers the private TypeScript Slang compiler with its own shader
assembler. Both backends use the same `shader.slang` and reusable `palette.slang` module.
WebGL 2 receives GLSL ES 300; WebGPU receives one WGSL program with generated entry points.
See the [Slang API](/docs/api-reference/slang) for compiler limits.
