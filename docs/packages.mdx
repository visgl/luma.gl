# Packages

luma.gl is a collection of composable GPU packages. Start with the primary packages,
then add the focused tools and integrations your application needs. Each card links
to the relevant package or subpath overview and API reference.

## Primary Packages

The building blocks for GPU resources, execution graphs, rendering, and shader composition.
WebGPU and WebGL2 backends are included in core through their own entry points.

<DocumentationModuleCards group="primary" />

## Smaller Packages

Focused packages and optional engine subpaths for text, computation, effects, assets, and data integration.
Availability and API maturity vary by entry point; check its overview before adopting it.

<DocumentationModuleCards group="smaller" />

## Exploratory modules

Explore scene APIs, shader languages, and rendering integrations under active development.
These APIs and supported workflows may change.
