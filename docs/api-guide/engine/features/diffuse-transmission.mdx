# Diffuse transmission and scattering

Diffuse transmission lets light emerge from the opposite side of a thin or scattering surface, useful for leaves, paper, and translucent ceramics.

The **DiffuseTransmissionPlant** sample demonstrates this capability. Drag to orbit and scroll to zoom.

## PBRMaterial reference

`PBRMaterial` from `@luma.gl/experimental` is a typed engine `Material` backed by the shared
`pbrMaterial` shader module. Its material fields are defined by `PBRMaterialUniforms` from
`@luma.gl/shadertools`. Pass them through `createPBRMaterial(device, {uniforms})` or update them with
`material.setProps({pbrMaterial: {...}})`.

The fields below are optional. Defaults are the shared shader defaults; imported assets can
supply other values.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `diffuseTransmissionFactor` | `number` | `0` | Fraction of dielectric diffuse energy transmitted into the opposite hemisphere. |
| `diffuseTransmissionColorFactor` | `Readonly<Vector3 \| NumberArray3>` | `[1, 1, 1]` | RGB tint of transmitted diffuse light. |
| `diffuseTransmissionMapEnabled` | `boolean` | `false` | Enables diffuse-transmission factor texture sampling. |
| `diffuseTransmissionColorMapEnabled` | `boolean` | `false` | Enables diffuse-transmission color texture sampling. |
| `thicknessFactor` | `number` | `0` | Volume thickness scale in model-space units. |
| `multiscatterColorFactor` | `Readonly<Vector3 \| NumberArray3>` | `[0, 0, 0]` | Experimental volume-scattering albedo. |
| `multiscatterColorMapEnabled` | `boolean` | `false` | Enables scattering-albedo texture sampling. |
| `scatterAnisotropy` | `number` | `0` | Henyey–Greenstein scattering anisotropy, ranging from -1 to 1. |

### PBRMaterialBindings

Texture resources are supplied separately through `PBRMaterialBindings`. Each field below is
optional and accepts `Texture | null`. `createPBRMaterial()` derives map-enabled flags from these resources. A model still needs
a compatible shader feature layout.

| Field | Description |
| --- | --- |
| `pbr_diffuseTransmissionSampler` | Texture resource for the `diffuseTransmission` slot. |
| `pbr_diffuseTransmissionColorSampler` | Texture resource for the `diffuseTransmissionColor` slot. |
| `pbr_multiscatterColorSampler` | Texture resource for the `multiscatterColor` slot. |

## Supporting APIs

### createPBRMaterial

`createPBRMaterial(device, {uniforms, bindings, factory})` from `@luma.gl/experimental` returns
a `PBRMaterial`. `uniforms` sets the fields listed above, `bindings` supplies material textures,
and the optional `factory` shares a compatible binding schema across materials. The helper
derives map-enabled flags from the supplied bindings; explicit uniform values take precedence.

### MaterialFactory

`createPBRMaterialFactory(device)` from `@luma.gl/experimental` creates a reusable engine
`MaterialFactory` configured with the `pbrMaterial` shader module. Pass this factory to
`createPBRMaterial()` when creating several compatible materials.

### Material

`Material` from `@luma.gl/engine` owns material uniforms and texture resources.
`setProps({pbrMaterial: {...}})` updates uniform values. Pass the material to a compatible
`Model` through its `material` prop; models sharing it observe the same updates.
Use `clone({bindings: {...}})` when an appearance needs separate texture resources.
Adding a texture or changing a shader feature may require matching defines and a compatible
model shader layout.

See the [materials guide](/docs/api-guide/engine/materials) and
[`pbrMaterial` reference](/docs/api-reference/shadertools/shader-modules/pbr-material).

## Usage

```ts
import {createPBRMaterial, type PBRMaterial} from '@luma.gl/experimental';

// device is an initialized Device.
const material: PBRMaterial = createPBRMaterial(device, {
  uniforms: {
    diffuseTransmissionFactor: 0.7,
    diffuseTransmissionColorFactor: [0.6, 0.9, 0.4],
    thicknessFactor: 0.2,
    multiscatterColorFactor: [0.8, 0.9, 0.6],
    scatterAnisotropy: 0.2
  }
});

// Pass material to a compatible Model through its material prop.
```

Scattering is a local, thickness-aware single-scattering approximation. Screen-space diffusion and random-walk multiple scattering are not implemented.

## glTF support

`KHR_materials_diffuse_transmission` is a release candidate rather than a ratified extension. The unratified `KHR_materials_volume_scatter` draft requires `KHR_materials_volume`. The plant sample demonstrates diffuse transmission; ScatteringSkull is a separate sample for the scattering draft.
