Packages

luma.gl is a collection of composable GPU packages. Start with the primary packages, then add the focused tools and integrations your application needs. Each card links to the relevant package or subpath overview and API reference.

Primary Packages​

The building blocks for GPU resources, execution graphs, rendering, and shader composition. WebGPU and WebGL2 backends are included in core through their own entry points.

  • @luma.gl/core

    Portable GPU resources, shader types, and WebGPU and WebGL2 backends.

    API reference →

  • @luma.gl/graph

    Schedule GPU work and compose graph-based processing pipelines.

    API reference →

  • @luma.gl/engine

    Models, geometry, animation, picking, and rendering helpers.

    API reference →

  • @luma.gl/shaders

    Compose WGSL and GLSL with reusable shader modules and hooks.

    API reference →

Smaller Packages​

Focused packages and optional engine subpaths for text, computation, effects, assets, and data integration. Availability and API maturity vary by entry point; check its overview before adopting it.

  • @luma.gl/engine/text

    Experimental

    Render GPU text with font atlases and reusable layout helpers.

    API reference →

  • @luma.gl/graph/gpu-simple-graph

    GPU data primitives and immediate compute operations without CPU readback.

    API reference →

  • @luma.gl/engine/effects

    Build post-processing pipelines with composable image and lighting effects.

    API reference →

  • @luma.gl/gltf

    Load glTF assets, materials, lights, skins, and animations.

    API reference →

  • @luma.gl/graph/arrow

    Experimental

    Convert Arrow vectors, tables and rendering data through optional /arrow subpaths.

    API reference →

  • @luma.gl/engine/splats

    Experimental

    Stream, sort, and render Gaussian splat scenes.

    API reference →

  • @luma.gl/core/test-utils

    Create test devices and inspect resource ownership with the null backend.

    API reference →

Exploratory modules​

Explore scene APIs, shader languages, and rendering integrations under active development. These APIs and supported workflows may change.

  • @luma.gl/anari

    Exploratory

    Describe 3D scenes and switch renderers through an ANARI-inspired scene API.

    API reference →

  • @luma.gl/slang

    Exploratory

    Compile Slang shaders with reflection and typed shader contracts.

    API reference →

  • @luma.gl/three

    Exploratory

    Combine luma.gl GPU workflows with Three.js scenes and renderers.

    API reference →

For a first application, follow Getting Started. For conceptual walkthroughs, browse the API Guide.
