Class: DynamicBuffer

Defined in: modules/core/dist/dynamic/dynamic-buffer/dynamic-buffer.d.ts:45

Optional convenience wrapper around an immutable core Buffer.

DynamicBuffer keeps a stable application object while allowing the backing GPU buffer to be replaced on resize. Engine classes such as Model and Material resolve it to the current backing buffer at draw time and invalidate cached bindings when generation changes.
