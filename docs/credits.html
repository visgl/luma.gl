Attributions and credits

luma.gl combines original vis.gl work with adapted graphics implementations, published research, and example datasets. We thank the contributors and upstream authors who make this work possible.

This page collects major implementation credits and scientific references. Full license terms remain in the repository license, source headers, adjacent notices, and the licenses of installed dependencies. A research citation credits an algorithm; it does not imply that its authors supplied luma.gl's code.

Project foundations​

The repository license credits Uber Technologies, Inc. for the initial open-source development, Sencha Labs for the PhiloGL portions, and the vis.gl contributors for the project's continued development.

luma.gl is part of the vis.gl ecosystem. Its development benefits from collaboration with deck.gl, math.gl, loaders.gl, and their contributors. Separately installed libraries retain their own licenses; the inventory below is not a transitive dependency inventory.

Citations​

Area lighting (LTC)​

Eric Heitz, Jonathan Dupuy, Stephen Hill and David Neubelt. Real-Time Polygonal-Light Shading with Linearly Transformed Cosines. ACM Transactions on Graphics (Proceedings of ACM SIGGRAPH 2016), 35(4), 2016. Author project page and paper.

luma.gl uses the fitted GGX tables from the upstream implementation for its optional LTC PBR area-light path. The tables and their retained notice are distinct from the shader assembly system. The numerical area-light fallback does not require the tables. See AreaLight and LTC PBR shading.

Physically based materials​

The PBR module reference records the shading literature used by the material implementation, including:

  • Brian Karis. Real Shading in Unreal Engine 4. SIGGRAPH 2013 course notes. Course notes.
  • Brent Burley. Physically Based Shading at Disney. SIGGRAPH 2012 course notes. Course notes.

These publications describe rendering methods. The adapted PBR source has the separate historical Khronos attribution recorded above.

Gaussian splatting​

Bernhard Kerbl, Georgios Kopanas, Thomas Leimkühler and George Drettakis. 3D Gaussian Splatting for Real-Time Radiance Field Rendering. ACM Transactions on Graphics, 42(4), 2023. Author project page, paper and citation.

This is a research reference for the Gaussian representation and rendering approach used by luma.gl's splat renderer. The Spark adaptations listed above have their own implementation credits and license.

Maintaining credits​

When adding adapted code or data, retain the upstream copyright and full license notice, record its source revision and material modifications, and include the notice in the package that distributes it. Update this page with the implementation credit and relevant research citation. For example assets, record the original creator, source and terms in an adjacent asset notice. Moving code between packages must also move its applicable notices.
