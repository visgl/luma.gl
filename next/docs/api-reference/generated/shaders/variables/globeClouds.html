Variable: globeClouds

const globeClouds: object

Defined in: modules/lighting/globe-clouds/globe-clouds.ts:15

Spherical cloud shell using the existing cloud density, noise and sunlight model. Camera and rays are globe-centered, with the planet's surface at unit radius. The shared clouds uniforms retain metre/second units; sunDirection is globe-centered XYZ.
