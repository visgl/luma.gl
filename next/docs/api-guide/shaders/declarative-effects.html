Declarative fullscreen effects

An effect definition is a typed object you can export from a module and reuse with multiple renderers. It describes the textures and draws needed for an effect. EffectRenderer allocates the textures, runs the passes, and manages history. The API is a prototype for fullscreen processing of rendered scene textures.

Apply effects to a scene​

Render the scene to sampleable color and depth textures. If you use shadow maps, render those and bind them to the scene materials during scene shading. The fullscreen stack then processes the shaded scene color.

import {EffectRenderer} from '@luma.gl/engine';
import {bloomLow, ssao} from '@luma.gl/engine/effects';

const effects = new EffectRenderer(device, {
  effects: [ssao, bloomLow],
  colorFormat: 'rgba16float'
});

effects.resize([width, height]);

// Run after scene rendering on each frame.
effects.renderToScreen({
  sourceTexture: sceneColor,
  bindings: {depthTexture: sceneDepth},
  uniforms: {
    ssaoEvaluate: {nearPlane: 0.1, farPlane: 200},
    bloomComposite: {intensity: 0.75}
  }
});

The effects run in array order. SSAO samples the scene depth and updates the color image. Bloom reads that updated image and adds glow. Use renderToTexture when another stage needs to sample the result. Call resize when the output dimensions change and destroy when the stack is no longer needed. The scene supplies and owns the input textures.

To use camera-reprojection TAA, add cameraReprojectionTaa between SSAO and bloom. Supply the camera matrices and jitter each frame as cameraReprojectionTaaResolve uniforms. After a camera cut, call resetHistory() before rendering the next frame. See the camera-reprojection shader definition for its camera uniform types.

The other fullscreen definitions include motionBlur, taa, and depthOfField. Motion blur and standard TAA use the scene velocity texture. Depth of field uses scene depth and camera and lens uniforms. Use depthOfField for separable blur or bokehDofEffect for a circular aperture. depthAwareBlurEffect runs horizontal and vertical filtering with scene depth and preserves edges across depth discontinuities. For a display-ready chain, place toneMappingEffect after HDR bloom and fxaaEffect after tone mapping.

Apply glfx image filters​

Import sepiaEffect, vignetteEffect, or another glfx definition from @luma.gl/engine/effects and add it to the stack. Use uniforms keyed by the shader name, for example uniforms: {sepia: {amount: 0.6}}.

CategoryDefinitions
AdjustbrightnessContrastEffect, denoiseEffect, hueSaturationEffect, noiseEffect, persistence, sepiaEffect, vibranceEffect, vignetteEffect
BlurbloomEffect, gaussianBlurEffect, tiltShiftEffect, triangleBlurEffect, zoomBlurEffect
StylizecolorHalftoneEffect, dotScreenEffect, edgeWorkEffect, hexagonalPixelateEffect, inkEffect, magnifyEffect
WarpbulgePinchEffect, swirlEffect

Use bloomEffect for the simple image filter and bloomLow for the HDR pyramid. Separable and repeated glfx filters declare both draws and reuse the shared color chain between them.

Configure an effect​

Use {effect, configuration} for settings that affect resources or pass order when building the stack. The renderer resolves the definition once at construction. Keep animated controls in the render call's uniforms so they can change without reallocating those resources.

import {EffectRenderer} from '@luma.gl/engine';
import {hdrBloom, ssaoEffect, ssr} from '@luma.gl/engine/effects';

const renderer = new EffectRenderer(device, {
  effects: [
    {effect: ssaoEffect, options: {normalSource: 'normal-texture', resolutionScale: 0.5}},
    {effect: ssr, options: {reprojection: 'camera', quality: 'fast'}},
    {effect: hdrBloom, options: {quality: 'ultra', downsample: 'auto'}}
  ],
  colorFormat: 'rgba16float'
});

Supply each effect's scene bindings at render time. SSAO in normal-texture mode needs the normal texture in addition to depth. Camera-reprojected SSR also needs camera uniforms. HDR bloom automatically selects fused compute on eligible WebGPU devices. Its fragment alternative produces the same named pyramid levels for the shared downstream passes.

The configurable catalog also includes outlines, selectionOutlineEffect, gtao, ssgi, hdrAutoExposure, volumetricFog, clusteredVolumetricLighting, and contactShadows. Use the heightFog definition for analytic fog with frame uniforms, or configure volumetricFog with {mode: 'height'}. Selection outlines sample a caller-provided selectionTexture mask.

Run compute pipelines​

A ComputePipelineDefinition is an ordered list of compute passes and reusable GPU operations. Each compute pass lists its kernels, maps shader binding names to named resources, and calculates dispatch dimensions from frame state. encodeComputePipeline resolves those bindings and records the passes into the caller's command encoder. Keep buffer and texture allocation in the renderer that owns them.

GPUConvolutionBloom executes fftBloomPipeline from @luma.gl/graph/gpu-effects. The definition makes highlight extraction, forward FFT, spectral multiplication, inverse FFT, and HDR composition explicit. The optical kernel transform runs only when its cached spectrum needs updating. FFTs reuse their existing compiled command graphs.

ClusteredLightGrid executes clusteredLightGridPipeline from @luma.gl/engine/lighting. Its clear, bin, and compact dispatches share one compute pass. Deferred and volumetric lighting continue to consume the resulting light counts and indices through the grid's bindings.

Capture scene geometry​

A SceneCapturePassDefinition names a framebuffer, declares attachment clear and depth settings, and supplies synchronous preparation and geometry hooks. encodeSceneCapturePass prepares GPU resources, opens the render pass, invokes the draw, and closes the pass. The scene supplies and owns the framebuffers and their texture attachments.

  • shadowMapCapturePass in @luma.gl/engine/lighting runs with the depth attachment view for each directional cascade, spot light, or point cube face.
  • deferredGBufferCapturePass in @luma.gl/anari clears the scene's MRT and depth attachments and returns the recorded draw count.
  • wboitCapturePasses records opaque depth, weighted accumulation, and revealage in that order. Both translucent passes reuse opaque depth.
  • aBufferCapturePass resets the head pointers and scissor before drawing a slice. The renderer resolves that slice before reusing its buffers.

Preparation and draw hooks let the scene supply view-specific models and bindings. The capture outputs remain available to the existing shadow sampling and fullscreen resolve stages.

Resolve scene buffers​

ANARI exposes fullscreen definitions for deferred direct lighting, ambient lighting, clustered deferred lighting, weighted blended transparency, and A-buffer transparency. Import them from @luma.gl/anari.

import {EffectRenderer} from '@luma.gl/engine';
import {clusteredDeferredLightingEffect} from '@luma.gl/anari';

const lighting = new EffectRenderer(device, {
  effects: [clusteredDeferredLightingEffect],
  colorFormat: 'rgba16float'
});

lighting.resize([width, height]);
const litColor = lighting.renderToTexture({
  sourceTexture: gBuffer.colorTexture,
  bindings: {...gBuffer.getShaderPassBindings(), ...clusteredLightBindings},
  uniforms: lightingUniforms
});

The scene renderer supplies and owns the G-buffer or transparency captures. The resolve samples those resources and writes the color result. For A-buffer resolve, use {effect: aBufferResolveEffect, options: {maxFragmentsPerPixel}} and match the limit used to capture fragments. The higher-level A-buffer, weighted blended transparency, and deferred scene renderers wire their own inputs automatically.

Author an effect​

Start with a fullscreen shader that follows the shader pass convention. Declare a pass for each draw and route each shader's inputs to the textures it samples. Use as const satisfies EffectDefinition<...> to check the definition while preserving its literal names and pass structure. This example adjusts contrast and then applies a vignette, reusing two built-in shaders.

import type {EffectDefinition} from '@luma.gl/engine';
import {brightnessContrast, vignette} from '@luma.gl/engine/effects';

export const softVignette = {
  name: 'softVignette',
  resources: {
    adjusted: {}
  },
  passes: [
    {
      kind: 'fullscreen',
      shaderPass: brightnessContrast,
      inputs: {sourceTexture: 'previous'},
      output: 'adjusted',
      uniforms: {contrast: 0.15}
    },
    {
      kind: 'fullscreen',
      shaderPass: vignette,
      inputs: {sourceTexture: 'adjusted'},
      output: 'previous'
    }
  ]
} as const satisfies EffectDefinition<'adjusted'>;
  • Resources are private to each occurrence of the effect. Set the texture format and scale when the default format or full resolution is unsuitable. EffectDefinition<...> checks that named targets are declared.
  • Inputs map shader binding names to textures. previous reads the current color chain and original reads the input to the entire stack. Supply scene textures such as depth in the render call's bindings.
  • Outputs select a named target or update the shared color chain with previous. Set per-pass defaults in uniforms and apply per-frame overrides by shader module name in the render call.
  • History uses lifetime: 'history'. Specify how to initialize the texture on the first frame or after a reset. A pass can read the previous frame and write the current frame using the same history target name.

Offer a WebGPU implementation with a fragment fallback​

Put the two implementations in initialPasses, then list their shared downstream draws in passes. Bloom declares half- and quarter-resolution extraction textures. Its compute branch writes both in one dispatch. Its fragment branch extracts highlights at half resolution, then downsamples to quarter resolution. Both feed the same blur and reconstruction passes.

For your own compute variant, map each storage binding to a named output and mark those resources with storage: true. The first output's dimensions determine the dispatch grid. The renderer checks WebGPU, storage-format support, binding limits, and workgroup dimensions. On other devices it runs the fragment sequence. Both paths should populate every resource the shared passes read.

Record a frame with EffectRenderer​

Use render({sourceTexture, target: null}) to draw to the canvas. Supply a framebuffer as target to draw into it, or omit target to return the output texture. The returned texture is borrowed. A later draw, resize, or destruction can overwrite or invalidate it. Rendering records commands without submitting. Use commandEncoder to record into a caller-owned encoder on the same device.

Set resetHistory: true on the first frame after a camera cut. Scene depth, normals, prepared light textures and buffers, and uniform values can change on each call.

A filter can reference its shader module directly:

const sepiaEffect = {
  name: 'sepia',
  passes: [{kind: 'filter', module: sepia}]
} as const satisfies EffectDefinition;

const renderer = new EffectRenderer(device, {
  effects: [
    {effect: ssaoEffect, options: {normalSource: 'normal-texture', resolutionScale: 0.5}},
    {effect: sepiaEffect}
  ]
});

The sepia amount remains a shader uniform. SSAO resolves its target scales and normal-source pass sequence from its definition when the renderer is created.
